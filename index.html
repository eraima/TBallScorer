    T-ball Scorebook user manual

    1. Set up a game

    Enter the date and optional ground or game name, choose the innings and hitter warning threshold, then enter both team names and each batting lineup (one player per line, in batting order). Press Save game setup. The game is saved in this browser on this device. On a phone, setup and batting order start collapsed after the game is saved; use their show/hide buttons whenever you need them.

    2. Move players and record plays

    Choose the batting team and inning. Select the next batter using the player list or the Next up button, then choose a base on the diamond or one of the move buttons. Select an occupied base to choose its runner. Runners move forward in order automatically when needed. Choose Out to record an out, or Skip player for a player who will not bat. Use Undo or Redo to step through recent scoring actions.

    The score notation marks the bases reached. If a player passes more than one base in a move, the visited bases are connected and an arrow points to the base where the player stopped. A home run is shown as four connected base dots.

    3. Read the scorecard

    The inning scorecard lists each batter, their base-by-base dots, and their result. The scoreboard at the top shows each team's running total. Use View scorecard to open the full-game scorecard with both teams, each inning, inning runs, and running totals.

    4. Export or share the scorecard

    Download scorecard (JPG) saves an image of the full-game scorecard, which you can print or attach to a message. On a device with image sharing, open the downloaded JPG in Photos or Files and use that app's Share button. Export JSON saves a data backup that can be kept or used to restore the game; it is not an image.
