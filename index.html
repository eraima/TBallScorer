        T-ball Scorebook user manual

        1. Set up a game

        Enter the date and optional ground or game name, choose the innings and hitter warning threshold, then select a team from the static team list or choose New team. Selecting a listed team fills its name and players; add, rename, remove, or move players up and down before saving. During a game, names can be changed and players added, but existing players cannot be deleted or reordered; stable player IDs keep their scoring attached when renamed. Press Save game setup.

        2. Move players and record plays

        Choose the batting team and inning. Select the next batter using the player list or the Next up button, then choose a base, OUT, or Skip player. Select an occupied base to choose its runner. Runners move forward in order automatically when needed. Choose OUT to record an out, or Skip player for an injured player. A skipped player can return later and their result stays in their original lineup spot. The inning button names the team and inning that will start next; use it to switch teams, then move to the next inning when both teams have finished. Warnings are displayed directly above the diamond. Use Undo or Redo to step through recent scoring actions.

        The score notation marks the bases reached. If a player passes more than one base in a move, the visited bases are connected and an arrow points to the base where the player stopped. A home run is shown as four connected base dots.

        3. Read the scorecard

        The inning scorecard lists each batter, their base-by-base dots, and their result. Select one or more rows, then select bases in the order reached and press Save changes. For example, Base 1 then Base 3 records that route; Home by itself records a home run; Base 1 then Out records an out after reaching first. Edits are not applied until saved. Run circles are green and out circles are red. The scoreboard at the top shows each team's running total. Use View scorecard to open the full-game scorecard with both teams, each inning, inning runs, and running totals.

        4. Export or share the scorecard

        Download scorecard (JPG) saves an image of the full-game scorecard, which you can print or share. Use Export JSON to save a data backup of your game.
